# Tài liệu dự án

Phiên mới bắt đầu tại [handoff](handoff.md), sau đó đọc [kiến trúc](architecture.md) và [quy ước](conventions.md). `AGENTS.md` ở root và frontend chứa lệnh/quy trình dành cho coding agent.

| Khi làm việc với | Tài liệu |
| --- | --- |
| PDF/OCR, block, snapshot, trình đọc và QA | [Module trình đọc](modules/document-reader.md) |
| Frontend và API client | [Module frontend](modules/frontend.md) |
| Tài khoản và xác thực | [Auth/users](modules/auth-users.md) |
| Cài đặt hiển thị | [Display settings](modules/display-settings.md) |
| DB, migration và test DB | [Database/migrations](modules/database-migrations.md) |
| Kế hoạch mở rộng trình bày văn bản | [Kế hoạch](text-presentation-plan.md) |

`handoff.md` có phần trạng thái hiện hành ở đầu và nhật ký lịch sử bên dưới. Khi quyết định cũ được thay thế, cập nhật phần hiện hành để phiên sau không dùng nhầm hướng cũ.
